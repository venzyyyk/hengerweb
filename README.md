# made by alekseyhenger

Портфолио-сайт: частицы на Three.js, скролл-сцены на GSAP + Lenis, 5 концепт-лендингов в `landings/`.

- `index.html` — главная (всё в одном файле)
- `landings/*/index.html` — концепт-лендинги
- `shoot.mjs` — шаг сборки на Vercel: копирует сайт в `dist/` и снимает свежие скриншоты всех проектов в `dist/shots/`

Деплой: Vercel собирает автоматически при пуше в `main`.
